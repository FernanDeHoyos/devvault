# Reportar una vulnerabilidad de seguridad

No publiques vulnerabilidades, detalles de explotación ni datos sensibles en
issues o pull requests públicos.

Usa la función **Report a vulnerability** de la pestaña **Security** de este
repositorio para enviar un aviso privado a sus mantenedores. Incluye la versión
afectada, el impacto, los pasos mínimos para reproducir el problema y cualquier
mitigación conocida. No adjuntes secretos ni datos de terceros.

Si la opción de reporte privado no está disponible, no publiques los detalles:
contacta a los mantenedores por un canal privado antes de divulgar la
vulnerabilidad. La opción de reportes privados del repositorio debe habilitarse
en GitHub para que los investigadores puedan usarla.

Los mantenedores confirmarán la recepción, evaluarán el alcance y coordinarán
una corrección y divulgación responsable con quien reportó el problema. No hay
un plazo de respuesta garantizado.

DevVault es una aplicación local y no tiene autenticación. No la expongas a
redes no confiables; consulta la sección de seguridad del README antes de
instalarla.
